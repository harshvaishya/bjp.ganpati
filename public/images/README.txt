HOW TO REPLACE IMAGES
======================
Simply replace these files in this folder with your own photos,
keeping the SAME file names. Do not edit any code — the website
will pick up the new images automatically.

image1.png  -> Ganpati Mandal / Family logo (a placeholder logo is
               already here — replace it with your real one)
image2.jpg  -> Ms. Priya Kesarwani
image3.jpg  -> Mr. Harsh Vaishya
image4.jpg  -> Mr. Sanskar Vaishya
image5.jpg  -> Gallery photo 1 — landscape, roughly 16:9 (e.g. 1600x900)
image6.jpg  -> Gallery photo 2 — portrait, roughly 3:4 (e.g. 1200x1600)
image7.jpg  -> Gallery photo 3 — portrait, roughly 3:4
image8.jpg  -> Gallery photo 4 — portrait, roughly 3:4
image9.jpg  -> Gallery photo 5 — portrait, roughly 3:4
og-image.jpg -> The picture shown when the link is shared on WhatsApp.
                Recommended size: 1200x630px. A placeholder is included.

If a photo is missing, the website will show a soft decorative
placeholder instead of a broken image — it will never crash the page.
