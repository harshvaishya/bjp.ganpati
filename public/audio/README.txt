HOW TO ADD BACKGROUND MUSIC
=============================
Place your music file here and name it exactly:

    background.mp3

That's it — the music button on the website will use it automatically.
Keep the file reasonably small (under ~3-4 MB) so the site stays fast
to load on mobile networks.

If this file is missing, the music button will simply do nothing when
tapped (no error, no crash) — the site works perfectly fine without it.
